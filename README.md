# หน้าแรกระบบจัดการขยะ (GitHub Pages)

หน้าแรกแบบเดียวกับ re-room / green-re: มีภาพรวมล่าสุด (เปิดดูได้ทุกคน), ลิงก์ด่วน และเปิดระบบภายในหน้านี้ แถบที่อยู่จึงยังเป็นลิงก์ GitHub

## ตั้งค่า (ครั้งเดียว)

1. เปิด `index.html` หาบรรทัด `appUrl:` (ใกล้ท้ายไฟล์ ในส่วน `CONFIG`)
2. แทนข้อความ `ใส่ลิงก์ /exec ของระบบจัดการขยะที่นี่` ด้วยลิงก์เว็บแอปจริง (Apps Script → Deploy → Manage deployments → คัดลอก Web app URL ที่ลงท้าย `/exec`)
3. บันทึกไฟล์

## อัปโหลดขึ้น GitHub

1. เข้า repository ที่ใช้เผยแพร่หน้าเว็บ (GitHub Pages)
2. Add file → Upload files → เลือก `index.html` จากโฟลเดอร์ `github-pages` นี้ (ไฟล์นี้จะแทน index.html เดิมบน GitHub)
3. Commit changes แล้วรอ 1–2 นาที เปิดลิงก์ GitHub Pages เดิมได้เลย

> ห้ามอัปโหลด `Index.html` (ตัวระบบ ~160 KB) หรือ `index (2).html` / `index (3).html` ในโฟลเดอร์หลัก ใช้เฉพาะไฟล์ในโฟลเดอร์ `github-pages` นี้

## ลิงก์ที่หน้าแรกใช้ (สร้างจาก appUrl อัตโนมัติ)

| ปุ่ม | ลิงก์ | ต้องกรอกรหัส |
|---|---|---|
| การ์ดเข้าสู่ระบบข้างเนื้อหาหลัก | `?view=gate` | (เป็นช่องกรอกรหัสเอง) |
| ผู้ได้รับสิทธิ์ (ปุ่ม 🔑 บนการ์ด) | `?login=1` | Username + รหัสผ่าน |
| ภาพรวมล่าสุด / เต็มจอ | `?view=poster&mode=group\|type` | ไม่ต้อง |
| เข้าสู่ระบบ | `/exec` | รหัสเจ้าหน้าที่ 7 หลัก |
| รายงานผู้บริหาร | `?go=execreport` | รหัสเจ้าหน้าที่ 7 หลัก |
| สรุปรายงานวิเคราะห์ | `?go=analysis` | รหัสเจ้าหน้าที่ 7 หลัก |
| บันทึกรายพื้นที่ / แบบตาราง | `?go=entry-area` / `?go=entry-grid` | บัญชีผู้ใช้ที่ได้รับอนุมัติ |
| คู่มือ | `?view=manual` | ไม่ต้อง |
| ลงทะเบียนรับรายงาน | `?page=register` | ไม่ต้อง |

ประวัติผู้เข้าดูอยู่ในชีต `AccessLog` ของไฟล์ Google Sheets
